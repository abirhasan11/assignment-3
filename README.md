## ✨ About

**Nature's Platter** is a modern landing page for an online grocery store, built as **Assignment 3**. It showcases fresh produce, popular products, special brand offers, customer reviews, and a newsletter signup. It is fully responsive and uses **Tailwind CSS** and **DaisyUI** for styling.

> Freshness you can count on, prices you'll love!

## 🚀 Features

- 📱 **Fully responsive** layout for mobile, tablet, and desktop
- 🥕 **Product cards** with images, ratings, and prices
- 🏷️ **Offer banners** with discounts and brand promotions
- ⭐ **Customer testimonials** with star ratings (DaisyUI)
- 📬 **Newsletter subscription** form in the footer
- 🎨 **Clean green theme** with the *Sora* Google Font
- 🔗 **Social icons** powered by Font Awesome

## 🧩 Page Sections

| Section | Description |
| --- | --- |
| **Navbar** | Logo, navigation links (Product, Services, Contact Us), search & cart icons, Login / Register buttons |
| **Hero banner** | "Freshness You Can Count On, Prices You'll Love!" with a vegetables hero image |
| **Services** | 24/7 Services, Fast Delivery, Healthy Products |
| **Popular Products** | 30% off promo card and a grid of product cards (Onion, Potato, Tomato and more) |
| **Arrival & Offers** | Brand offer banners (Dawat, India Gate) with up to 20% / 40% off |
| **Clients Say** | Customer reviews with ratings |
| **Footer** | Newsletter signup, quick links, and social media links |

## 📦 Getting Started

No build step is needed. Everything loads from CDNs, so you just need a browser and an internet connection.

```bash
# 1. Clone the repository
git clone https://github.com/your-username/assignment-3.git

# 2. Go to the project folder
cd assignment-3

# 3. Open index.html in your browser
```

You can also use the **Live Server** extension in VS Code, or run:

```bash
npx serve .
```
